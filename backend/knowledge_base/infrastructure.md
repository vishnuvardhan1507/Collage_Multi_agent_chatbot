# Campus Infrastructure

The Innovation Block includes Lab-302, Lab-305, and the project studio. Lab-302 has 36 seats
and is commonly used for machine learning and database lab sessions.

The Main Block includes A-101, A-102, and two lecture halls. A-101 has 60 seats and supports
projector-based teaching.

The Admin Block includes Seminar-1, the examination cell, and the student help desk.
Seminar-1 has 120 seats and can be booked for department talks, placement briefings, and
orientation events.
